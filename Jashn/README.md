## Why Jashn

Planning a celebration means juggling money, dates, suppliers and a hundred small decisions, and it is easy for something important to be forgotten until it is too late. Jashn turns what you already know about your event (type, date, guest count and budget) into a plan you can follow from the first idea to the final thank-you.

It is built for families, couples and community organisers who want clear guidance without hiring a planner or maintaining spreadsheets. It adapts to the number of guests, the size of the budget and the time left. It also works **with or without an AI key**: Google Gemini adds fresh ideas and answers, and a deterministic built-in planner keeps every feature working when AI is unavailable.

**The challenge it addresses:** a GenAI-powered planning assistant that helps users organise weddings, birthdays and community events with budgets, timelines, vendor checklists and personalised ideas.

---

## How it works

1. **Describe your event.** Choose a wedding, birthday or community event, then enter the name, date, guest count and total budget. Optionally add a city, theme, interests and budget priorities.
2. **Jashn builds your plan.** Every field is validated with Zod, then the budget, timeline, vendor checklist and ideas are generated by a deterministic, tested engine.
3. **Review and track.** Tick off tasks, enter what you spend and watch your progress. Your plan is saved in your own browser.
4. **Ask and refine.** The AI assistant calls Google Gemini. If a model is out of quota or unavailable, the next model in the chain answers; if none can, the built-in planner does.
5. **Share.** Export a synchronized `.ics` calendar file for Google and Apple calendars, print a clean tabular checklist formatted for binders, or copy a direct URL containing your entire plan configuration without requiring an account.

## Key features

### Budget
- Splits your total across categories (venue, food, decor, entertainment and more) and **always adds up exactly** (the "math integrity invariant" using the Hare-Niemeyer largest-remainder method).
- Indian currency formatting (₹, lakh/crore grouping).
- **Protected contingency reserve:** 10% base reserve (+5% outdoor weather surcharge) locked against unforeseen expenses.
- **Up to 3 budget priorities:** Automatically rebalances category allocations when you prioritise specific areas (e.g., photography or catering).
- **Per-category spend tracking:** Track actual expenses against allocated amounts with real-time balance calculations.
- **Over-budget warnings:** Clear visual alerts and guidance if spending exceeds category allowances.

### Timeline
- Counts tasks back from your event date, grouped into phases from early planning to after the event.
- **Dynamic schedule compression:** Scales task deadlines proportionally when your event is closer than the recommended lead time, preventing dates from slipping into the past.
- **Critical path & dependencies:** Identifies blocking prerequisites so foundational items (like booking the venue) happen first.
- **Live status indicators:** Instant visibility on tasks that are `Pending`, `Due Soon`, `Overdue`, or `Completed`.

### Vendor checklist
- Vendors with budget share and booking deadlines, ordered chronologically by lead time.
- **Standard booking steps:** Step-by-step checklist per vendor (consultations, tasting sessions, contract signing, advance payments).
- **Negotiation questions:** Practical, culturally tailored questions to ask vendors before signing agreements.
- **Essential vendor flags:** Critical vendors (like venues, catering, or weather canopies) flagged so high-priority bookings are secured early.

### Personalised ideas
- Ideas tailored to your theme, interests, guest count and budget, with Indian cultural celebration nuances.
- AI-generated ideas through Gemini, using structured (Zod-validated) output.

### AI assistant
- Powered by Google Gemini with **priority failover** across models (`gemini-2.5-flash` → `gemini-1.5-flash` → `gemini-1.5-pro`).
- Falls back to the **100% deterministic built-in mode** when no key or model is available, with full offline capability.
- **Floating chat on every page:** Accessible, persistent AI assistant with chat history stored locally.
- **Plan-aware answers:** Injects your active celebration context (budget, guest count, dates, categories) into advice.
- **Source attribution:** Transparent badges indicating whether responses originated from Gemini or the built-in deterministic engine.
- **One-click what-if simulations:** Apply budget cut or reallocation scenarios directly from assistant suggestions.

### Privacy, security and accessibility
- No account needed. Plans are persisted client-side with Zustand and `localStorage`.
- Strict CSP headers, prompt-injection defences, sliding-window rate limiting and a zero-XSS design. See [`docs/SECURITY.md`](docs/SECURITY.md).
- WCAG 2.1 AA checklist, keyboard maps, colour contrast and reduced-motion support, audited with axe-core. See [`docs/ACCESSIBILITY.md`](docs/ACCESSIBILITY.md).

## 🛠️ Technology Stack

- **Framework:** Next.js 14 App Router + TypeScript
- **Styling:** Tailwind CSS (Curated Deep Indigo `#2E2A7A`, Marigold `#F5A524`, Berry `#B83280`, Teal `#0E6B6A`)
- **State Management:** Zustand with client-side persistence (`localStorage`)
- **Validation:** Zod schemas
- **AI Engine:** Google Gemini API (`@google/genai`) with priority failover (`gemini-2.5-flash` → `gemini-1.5-flash` → `gemini-1.5-pro`)
- **Unit & Integration Testing:** Vitest with V8 Coverage
- **End-to-End Testing:** Playwright (Chromium)
- **Accessibility Auditing:** Axe-core (`@axe-core/playwright`)
- **CI / CD:** GitHub Actions (`.github/workflows/ci.yml`) & Vercel deployment ready

## 🚀 Quickstart Guide

### 1. Prerequisites
- Node.js 18.x or 20.x+ (tested on Node v20 & v24)
- npm 9+

### 2. Installation
```bash
git clone https://github.com/shoaibkhan-sde/Jashn.git
cd Jashn
npm install
```

### 3. Environment Setup (Optional)
Copy `.env.example` to `.env.local`:
```bash
cp .env.example .env.local
```
*(Note: If you do not supply a `GEMINI_API_KEY`, Jashn runs automatically in **100% Deterministic Built-in Mode** with full offline capabilities!)*

### 4. Running Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
